# To-Do Manager

## Project description

To-Do Manager is a simple web application made for Code2Work. It helps students organize their daily tasks.

The user can create a task, change its status (`to do`, `in progress`, `done`) and delete it. The tasks are saved in the browser (`localStorage`), so they are still there after a page refresh.

## Technologies used

- Vue.js 3
- TypeScript
- Vite
- ESLint
- Prettier

## Project initialization

The `node_modules` folder is not included in the repository, so the dependencies must be installed first:

```sh
git clone https://github.com/asmabh04/to-do-manager.git
cd to-do-manager
npm install
```

## Project launch

```sh
npm run dev
```

Then open the address shown in the terminal (usually http://localhost:5173).
